# 旧功能代码清理记录

## 当前业务代码

当前运行入口为 `api/app.py` 和 React 前端，视频业务只装配快速创作的 StandardPipeline、直连媒体 API、Edge/MiniMax 配音，以及 COS 作品管理和分镜编辑。

以下旧实现已删除：

- Streamlit 的页面、状态、组件和工作流 UI。
- RunningHub / ComfyUI / ComfyKit 的执行服务、工作流工具和已跟踪 JSON 工作流。
- 素材创作、数字人、动作迁移及独立图生视频页面、对应流水线和图像/视频分析服务。
- 旧 API routers、schemas 和内存任务管理器。
- 旧 Windows 打包脚本和模板。
- 素材创作流水线专用的素材文案提示词。LLM/VLM 客户端、模型预设、连接检查工具和通用风格转换提示词作为扩展能力保留。
- 直连媒体服务中数字人/动作迁移使用的 4 个模型注册、能力元数据、专用输入参数和提供商调用分支。快速创作中的图生视频分镜继续保留。
- 8 个提供商客户端中的旧手工演示入口，以及旧工作流 FAQ；清理资源工具和画面处理代码中的过时注释。
- 无运行调用的 FastMCP、MoviePy、python-multipart 直接依赖及其不再需要的间接依赖，重新生成锁文件并同步虚拟环境。

没有通过隐藏入口保留旧服务。对当前 API/核心 Python 代码的静态导入检查未发现对已删除模块的引用。

## 明确保留的内容

- LLM/VLM 扩展模块：`api_services/llm_*.py`、`api_services/vlm_*.py`、`llm_presets.py`、`utils/llm_util.py` 和 `prompts/style_conversion.py`。这些模块用于后续文章、图文理解等内容功能；当前页面未调用不构成删除理由。
- `config/schema.py` 中的旧配置迁移读取逻辑：从既有配置提取可用配音/媒体设置，并清除非直连模型默认值；不执行旧工作流。
- 旧历史中的工作流名称和分镜字段：用于读取、展示、迁移和恢复时重新选择模型，避免丢失原记录。
- 任务临时文件和本地模板/音乐导入工具：用于 FFmpeg/Chromium 处理和初始化 COS，不作为作品持久存储。
- 原有未跟踪测试、调查文件、`.claude/`、CLAUDE.md、旧 `output` 和配置：未删除用户既有文件。部分测试属于退役接口，不参与当前平台的默认验收。
- 可选自带 NGINX 部署文件：现有网关部署只启动 app，自带网关 profile 不启用；也提供了现有 NGINX 的转发示例。

因此，运行中的旧功能实现已清理；仓库仍可搜索到兼容迁移、归档说明及用户原有文件中的旧名称。

## 验证

清理后 Python 平台测试 30 项及兼容历史/图片尺寸回归 6 项，共 36 项通过；Python 导入、编译、依赖锁一致性和改动代码 Ruff 检查通过。浏览器 Chromium/WebKit 共 12 项通过，前端 TypeScript/Vite 生产构建通过。专项测试覆盖退役模型拒绝、快速创作首帧视频参数链以及代理环境恢复。真实 COS 和现有 NGINX 部署联调状态见 `docs/verification.md`。

用户随后确认 LLM 模块用于未来扩展，已恢复 9 个 LLM/VLM 客户端及模型预设、连接工具、通用风格转换提示词，共 12 个文件，并恢复提示词公开导出。此前删除这些扩展模块的决定已撤回。
