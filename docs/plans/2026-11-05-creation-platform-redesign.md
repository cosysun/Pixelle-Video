# Pixelle 创作平台改造方案

归档日期：2026-11-05。状态：代码改造完成，真实 COS / HTTPS / 容器部署待环境联调。

## 已确认的目标

- 精简为快速创作和统一作品库，保留完整分镜编辑；删除素材创作、数字人、独立图生视频、动作迁移以及 RunningHub、ComfyUI。
- React + TypeScript + Vite 前端，FastAPI 模块化后端；公共登录、设置、模型、任务、资源和作品服务与视频模块解耦。未来文章模块独立注册，本次不提供空入口。
- SQLite 保存目录、任务、批次、设置和会话；作品内容、素材、修订和自定义资源全部存私有腾讯云 COS。允许临时下载与合成，任务结束后清理，不持久化本地作品目录。
- 一个账号密码登录，服务器环境变量配置；七天服务端会话、HttpOnly/Secure/SameSite Cookie，所有业务接口鉴权，凭据不返回前端或写入 COS。
- Docker 部署；NGINX 可选入口，挂载已有证书、托管静态页面和代理 API；已有网关时可复用，无需重复部署代理。

## 界面与移动端

暖白背景、白色内容区、灰色细边框、紫色强调、统一线性图标与留白；建立统一字体、间距、按钮、表单、弹窗和状态规范。

- 桌面：侧栏导航、内容编辑、固定预览；平板收缩导航；手机单列、底部创作/作品导航、全屏编辑和设置面板。
- 主题/固定文案、可选标题、可编辑文案预览、一键生成；模板和画幅、直连图片/动态视频、配音试听、语速、音乐试听和音量；高级参数折叠。
- 批量最多 100 个主题，逐项进度、取消与失败重试；作品搜索、状态筛选、排序、分页、预览、下载、复用与确认删除。
- 视频详情保留标题、音乐、分镜增删、局部画面/配音重生成、全部配音重生成、模板替换和重新合成。
- 草稿自动保存，失败保留输入；过期文案提示；刷新不停止任务；触控区域至少 44px、安全区域、键盘与 reduced-motion 适配。

## 存储和可靠性

统一对象存储接口，服务器 SDK 操作和浏览器限时签名链接；仅为已登记且获授权的资源签名。上传申请、COS 直传、大小/类型确认，最大 100MB；跨域仅允许应用域名。

每个素材完成后上传并保存检查点；使用不可变对象键和修订清单，上传成功后在 SQLite 切换版本。错误保留旧版本，恢复从 COS 取回素材。删除可重试且不删除共享资源。旧作品迁移可重复执行，校验后入库，不自动删除本地原件；旧工作流记录重生成必须选择直连替代模型。

任务以类型注册；新生成 ID 与作品一致，编辑任务关联作品；同作品互斥；默认串行；活动任务两秒查询。重启标记中断，手动恢复，不自动重复调用付费模型。
