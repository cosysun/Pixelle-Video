    投资资产跟踪¶

    网站首页及登录后默认进入“投资”，地址为 /investment。组合收益率曲线默认展示“本交易日”。电脑侧栏或手机底部可进入“创作”，地址为 /studio。投资数据保存在现有 SQLite 数据库，和视频作品分别管理。

    本机预览可执行 PIXELLE_COOKIE_SECURE=false uv run python -m api.app --host 127.0.0.1 --port 8000，再访问 http://127.0.0.1:8000/investment。这项环境变量仅适用于本机 HTTP 预览；部署到 HTTPS 时继续使用默认安全 Cookie 配置。

    开始使用¶

    已有 portfolio-index 时，从应用目录执行一次迁移：

    uv run python -m pixelle_video.platform.cli investment-migrate --root /path/to/portfolio-index

    命令读取旧目录中的账本、持仓快照、人工估值和行情缓存，保留源文件。首次进入页面可点击“数据说明”查看迁移核对信息，尤其是港股通实际人民币结算金额、其他资产估值日期以及起点前历史是否齐全。相同源数据重复迁移不会重复记账。

    明确用于建仓的旧持仓快照只与期初数量进行核对，差异写入迁移报告。核对不会覆盖后续持仓，也不会生成新的买卖或现金流水。

    没有旧账本时，导入 Excel 的持仓快照建立明确日期的起点，再记录期初现金与投入本金；交易工作表和持仓快照不能叠加为两份持仓。导入前会展示工作表、字段映射、无效行及疑似重复行，确认后才入账。

    日常记录¶

    • 买卖：填写市场、证券代码、数量、成交单价及费用。港股通采用港币报价、人民币结算，应填写交割单实际人民币金额与费用，缺少时标为汇率估算。
    • 入金、出金：记录外部资金流动，影响总资产及净投入，不直接增加投资盈亏。
    • 换汇：填写转出和到账币种、金额，作为组合内部转换，不算外部投入。
    • 分红、费用、拆股：分别记入账本；拆股比例为新股数除以原股数，例如 1 拆 2 填 2。
    • 其他投资：填写最新单位净值或总金额及估值时间，未更新期间沿用已知估值。

    投资流水默认收起，点击标题展开或收起；“新增记录”入口始终可用，收起再展开保留筛选与分页状态。记录可编辑或作废，历史版本可查看。仅有日期的记录在北京时间该日结束时入账，不虚构成交时间。当天日期记录会在当日结束后进入资产计算；需要马上反映的成交请填写真实时间。

    数字与曲线¶

    总资产为持仓与分币种现金按参考汇率折算的人民币价值；外币现金会随汇率重估。累计盈亏为总资产减累计净投入，包含起初持仓浮盈和开始跟踪后的收益。缺少起点前已卖出股票的记录时，页面明确注明历史范围。

    页面分别显示总资产、累计盈亏和组合收益率三张曲线，均支持时间范围选择及悬停、触摸查看。收益率分两个口径：默认“本交易日”显示交易日收益率，即每个采样点的交易日盈亏除以上一交易日日终总资产，再乘以 100%；分子扣除期间净出入金，基准与交易日盈亏卡片一致，下一交易日重新起算。上一交易日日终资产不大于零或估值、出入金资料缺失时不计算。这个比例采用固定期初资产作分母，盘中出入金金额从盈亏中扣除，不按资金在场时间加权。

    “近一周、近一月、近三月、全部”显示包含期初收益的复利累计收益率。以最早日线观测的已有收益率为起点，即该时点累计盈亏除以累计净投入；当前旧账本基准日期为 2026 年 10 月 20 日，估值截止为次日北京时间 08:00。保留当天的浮盈浮亏，不将该日收益率设为 0%。之后按 (1+起点收益率) × (1+r1) × (1+r2) × … − 1 连乘；盘中发生出入金时，后续投资表现继续使用时间加权收益率（TWR）分段衔接，剔除外部资金影响，非年化。切换四档只改变展示区间，不重设起点，不直接相加收益率。

    无后续出入金时，这条曲线与相同时点的本金收益比例一致；发生出入金后，曲线保持复利衔接，卡片按当时累计净投入计算，两者可能不同。起点之前已卖出资产的历史盈亏仍受原始账单缺失限制；这里的期初收益率是已迁移账本可核对的比例，不补造缺失历史。

    首页集中显示数据和必要状态，公式、起点及曲线操作集中在“数据说明 → 计算口径与曲线说明”中查看。图表标题明确区分“交易日收益率走势”和“复利累计收益率走势”，交易日盈亏卡片同时显示交易日收益率。曲线末点与顶部卡片采用各自标明的估值时间。

    累计盈亏卡片保留“本金收益比例”，即累计盈亏除以累计净投入，包含期初浮盈浮亏；出入金会改变分母。净投入不大于零或估值缺失时显示缺失值。

    每笔出入金前用缓存中的历史价格、汇率估值，将该段收益连接，再以出入金前资产加上外部资金为下一段基数。手续费留在投资收益中，买卖、分红、换汇与拆股不作为外部资金。仅日期记录或沿用较早价格、汇率的出入金边界标为估算；缺少边界估值、历史汇率或边界前后资产不大于零时，后续复利累计收益率保持缺失，补齐资料后重新计算。普通采样缺失时只连接已有有效点，不生成新的金额记录。前端长期收益率曲线使用 compounded_return 及其 compounded_warning，沿用时间加权分段估值的估算标记。接口保留从零起算的纯 time_weighted_return 供核对，return_baseline_rate 明确实际期初收益率；本交易日使用 daily_return，本金收益比例使用 cumulative_return。缺少期初盈亏或净投入时，复利累计收益率显示缺失，不能默认以 0% 开始。

    交易日盈亏与上一已结束交易日日终资产比较，再扣除期间净出入金。A 股、港股、美股当地同一日期的交易归入同一天，美股跨北京时间零点继续计入。下一交易日首个市场常规交易开盘时切换；周末、节假日及开盘前保留上一交易日结果，交易日最终值以次日北京时间 08:00 截止。分市场盈亏包含持仓原币市值变化和该市场买卖、分红、费用引起的现金变化，按期末汇率折算；汇率重估、换汇和其他资产变化列入“汇率 / 其他”，各项合计等于交易日盈亏。单只证券涨跌与所属市场前收盘价比较。三张曲线按真实有效数据点的先后顺序等距连接，午休、休市和缺少行情的时间间隔均收起，横轴不表示实际时间长度。“本交易日”的采样范围仍由交易日历确定，夏令时、节假日和半日市按日历调整。只展示交易时段的有效采样；正在交易的持仓行情超过正常报价延迟与五分钟更新容差时，跳过该点的缺失金额。腾讯港股免费报价约延迟 15 分钟，按实际源时间估值并标为延迟行情 / 估算；超过约 20 分钟且不属于午休或已收盘的正常停更时仍跳过。其他报价继续采用五分钟容差。港股延迟报价在午休后沿用最近有效交易时刻判断，收盘后继续采集最多 20 分钟以取得实际收盘源报价。已验证收盘行情可放在收盘位置，悬停仍显示行情实际时间，不生成缺失分钟。上一交易日日终值作为盈亏基准保留，不占盘中横轴。历史日线统一在北京时间次日 08:00 截止，使用截止前最近已完成的各市场收盘价。日线按所属日期展示，悬停日期可查看次日 08:00 估值截止时间。长周期在日线末尾衔接最近实际采样值，日线、盘中点和收盘点保留各自标签。连接线用于展示相邻有效值的变化，不新增中间金额或分钟记录；悬停显示每个点的真实时间。

    运行与备份¶

    服务器运行期间，交易时段每 60 秒采集一次，关闭页面仍继续。采集与视频任务队列独立，多个页面共享缓存。美股仅跟踪常规交易时间，日历处理午休、节假日、夏令时及半日市。

    腾讯报价及东方财富历史行情、汇率为免费参考数据，页面展示源时间。接口失败时沿用已知值并提示过期；缺少价格或汇率时标为不完整，不将缺失估值计为零。分钟快照保留 90 天，日线长期保存。

    备份 PIXELLE_DATABASE 指定数据库。应用运行时应使用 SQLite backup API，避免只复制活动数据库而漏掉 WAL。原始投资文件与数据库属于个人数据，不提交到 Git。
